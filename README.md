# Here, a Peach Grove

A hand-tracked mixed reality experience for Meta Quest 3. Let a butterfly land in your palm, then watch a peach grove emerge around you when it takes flight.

## Install on Quest 3

1. Download [the v0.12 APK](../../releases/tag/v0.12-quest).
2. Enable developer mode on your headset. Connect it via USB and allow USB debugging.
3. Run the following command with Android Platform Tools, then open **此间桃源 Quest** in the headset's app library.

   ```sh
   adb install -r Here-a-Peach-Grove-Quest3-v0.12.apk
   ```

## Play

Use a clear play area. Follow the opening cue and offer your right palm to the butterfly. In the grove, you can pluck the guqin, pick a blossom, and touch the water. Once the left-hand cue appears, hold your left palm up to begin the farewell.
